# Отчет о внедрении System Design и архитектурной устойчивости: weather-forecast

> **Статус:** Имплементировано  
> **Область:** Upstream OpenWeather Circuit Breaker, Stale-While-Revalidate Resilient Caching, Exponential Backoff with Full Jitter, 24h Geocoding Caching  
> **Дата аудита и внедрения:** Октябрь 2026

---

## 1. Контекст и архитектурные вызовы

`weather-forecast` предоставляет прогноз погоды и геокодирование городов.
Ранее:
1. **Каскадные сбои при деградации OpenWeather:** Если внешнее API OpenWeather отдавало 502/503 или превышало лимиты (429), каждый пользовательский запрос блокировался по таймауту и безуспешно повторял вызовы.
2. **Отсутствие Stale-кэша:** При истечении TTL (5 мин) при недоступности внешнего провайдера пользователь получал ошибку 502, хотя в памяти имелись актуальные данные за предыдущие часы.
3. **Неэффективный бэкофф:** Повторные попытки использовали фиксированный узкий интервал задержки, не снижающий нагрузку на провайдера.

---

## 2. Реализованные архитектурные решения

### 2.1. Circuit Breaker для OpenWeather (`src/circuit-breaker.js`)
* Реализован конечный автомат состояний:
  - `CLOSED`: Нормальная работа. Ошибки инкрементируют счетчик `failureCount`.
  - `OPEN`: При достижении порога `failureThreshold = 4` за 20 секунд отсекает запросы без сетевого ожидания.
  - `HALF_OPEN`: По истечении периода восстановления `recoveryTimeoutMs = 20s` пропускает один пробный запрос. При успехе сбрасывает автомат в `CLOSED`, при ошибке — снова переводит в `OPEN`.

### 2.2. Stale-While-Revalidate Resilient Cache (`src/cache.js`)
* Разделение жизненного цикла кэша:
  - Свежие данные (`fresh`): до 5 минут.
  - Устаревшие данные (`stale`): до 24 часов.
* При срабатывании Circuit Breaker или временном отказе OpenWeather сервис автоматически отдает `stale` данные с флагом `meta.stale = true` и `meta.cacheHit = true`, обеспечивая бесперебойную работу интерфейса.

### 2.3. Full Jitter Exponential Backoff & Geocode Cache (`src/weather-service.js`)
* Экспоненциальный бэкофф с полным случайным разбросом:
  $$\text{delay} = \text{random}(0, \min(2000, 150 \times 2^{\text{attempt}}))$$
* Кэширование геокодирования городов на 24 часа (`geocodeCache`), экономящее лимиты запросов OpenWeather API.
